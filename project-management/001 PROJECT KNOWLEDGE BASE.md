## Identidad

### Resumen Ejecutivo

EnergIA es una plataforma inteligente diseñada para analizar patrones de consumo energético mediante Ciencia de Datos e Inteligencia Artificial. El sistema clasifica perfiles energéticos, estima costos de consumo y genera recomendaciones para mejorar la eficiencia energética, integrando una API REST y Oracle Cloud Infrastructure (OCI).

### Visión

Convertir a EnergIA en una plataforma de referencia para el análisis inteligente del consumo energético y la promoción de hábitos sostenibles.

### Misión

Desarrollar un MVP funcional que combine Ciencia de Datos, Inteligencia Artificial, desarrollo Back-End e infraestructura OCI para ofrecer análisis energéticos confiables y recomendaciones prácticas.
