## Cómo ejecutar el frontend

```bash
cd frontend
npm install
npm run dev
```

La aplicación queda disponible en `http://localhost:5173`. Ver más detalles, credenciales de ejemplo y variables de entorno en el [README del frontend](./frontend/README.md).
